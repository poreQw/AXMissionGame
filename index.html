ABOUT THIS PROJECT

项目介绍

AX QUEST v2.0 是一款帮助学习者认识人工智能与信息技术词汇的三语问答小游戏。完成任务可获得 XP、提升等级并解锁专属徽章。

项目目的

用简短、有互动感的游戏方式学习 AI 与 IT 术语，帮助玩家建立三种语言之间的词汇联系。

适用对象

适合对人工智能感兴趣的初学者、学习中文/英文/韩文的学生，以及希望轻松复习技术词汇的用户。

游戏规则

  • 词汇按基础到高级排序，每轮依次学习接下来的 10 题。
  • 每题有 4 个选项，限时 20 秒，每题只能作答一次。
  • 答对得 10 分，答错或超时得 0 分，满分 100 分。有效作答可获得 XP，答对与快速作答有额外奖励。

主要功能

  • 三语词汇练习、拼音辅助、即时正误反馈与答案回顾。
  • 答题页显示进度和当前得分；结果页展示总分、XP、等级进度、升级提示与解锁徽章。
  • 累计 XP 提升等级；首个任务、70% 正确率、满分、五连对和累计 500 XP 可解锁徽章。
  • 最近 10 次已完成任务会保存成绩和错题词汇，方便之后复习。
  • 等级、XP、徽章、学习记录与最高分保存在当前浏览器，刷新后仍然保留。
  • 可在设置中切换韩语、简体中文和英语界面。

开发技术

使用 HTML 搭建页面结构、CSS 实现视觉样式和响应式布局，使用原生 JavaScript 实现题库抽题、计时、XP、等级和徽章；使用 LocalStorage 保存玩家进度、最近 10 次学习记录与最高分。无需安装依赖。

开发中遇到的问题

需要保证随机抽题与选项均不重复、选项只有一个正确答案，并妥善处理超时和重复点击；同时还要兼顾不同屏幕尺寸与本地成绩保存。

学到的知识

练习了用 JavaScript 管理游戏状态、打乱数组、控制计时器、更新 DOM、进行本地存储，以及使用 CSS Grid 和媒体查询构建移动端界面。
